# Security policy

This repo holds example configs, diagrams and a threat model. It holds no credentials.

## Reporting a problem

- A weakness in a configuration or recommendation here: open a private report through the repository's Security tab (Report a vulnerability).
- Another way to reach us: https://truvocyber.com/contact-us

Include the OpenClaw, Lume and macOS versions and the steps to reproduce. Please do not post exploit details in a public issue.

## Scope

In scope: incorrect or unsafe guidance in the configs, diagrams or threat model.
Out of scope: vulnerabilities in OpenClaw, Lume, macOS or Slack. Report those to the vendor or project.
